# Read It To Me

Photograph any official document on WhatsApp — a consent form, prescription, bill, bank or court letter —
and get a plain explanation in Hausa, Yoruba, Igbo, Nigerian Pidgin or French, written and spoken,
with every point linked to the exact line it comes from.

Built for the Meta Global AI Developer Hackathon (26 Oct – 4 Nov 2026) with SAM 3.1 and Muse Spark
via the Meta Model API.

Status: building. Planned pipeline: WhatsApp Cloud API → SAM 3.1 (isolate the document) →
Muse Spark (read and explain, quoting source lines) → speech in Nigerian languages → reply on WhatsApp.

Author: Chinasa Joyce Onwe — Lecturer, Department of Foreign Languages, AE-FUNAI.
